# Практика №3. Технологии сетевого взаимодействия в программах

Репозиторий содержит реализацию двух сетевых программ на языке C++ для работы с сетевыми службами по протоколам UDP и TCP.

## Структура проекта
* daytime/ - каталог с UDP-клиентом для получения времени.
  * daytime_client.cpp - исходный код программы.
  * Makefile - сценарий сборки утилиты make.
  * .gitignore - исключение исполняемых файлов из Git.
* echo/ - каталог с TCP-сервером службы echo.
  * echo_server.h - заголовочный файл с объявлением класса сервера.
  * echo_server.cpp - реализация сетевой логики сервера.
  * main.cpp - точка входа для запуска сервера.
  * Makefile - модульный сценарий сборки.
  * .gitignore - исключение исполняемых файлов из Git.

---

## 1. Сетевая служба daytime (UDP-клиент)
Программа отправляет пустую датаграмму на сервер, ожидает ответ и выводит текущую дату и время на экран.

### Сборка и запуск:
```bash
cd daytime
make
./daytime_client
```

## 2. Сетевая служба echo (TCP-сервер)
Сервер слушает порт 7777 на всех сетевых интерфейсах, принимает подключение от утилиты nc, считывает входящие символы и отправляет их обратно клиенту.

### Сборка и запуск сервера:
```bash
cd echo
make
./echo_server
```

### Тестирование сервера:
Для проверки работоспособности сервера используется утилита nc:
```bash
nc 127.0.0.1 7777
```
После подключения введите любой текст в терминале с nc и нажмите Enter - сервер вернет этот текст обратно.
